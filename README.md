# Gigi à Paris

Corso di francese interattivo (livelli A1–A2) con episodi a puntate, trucchi per ricordare le parole, audio di pronuncia (voci del dispositivo) e un test per ogni lezione.

**Apri il corso:** https://vitovilante-png.github.io/gigi-a-paris/

I progressi vengono salvati nel browser di chi segue il corso.

Le fotografie provengono da Wikimedia Commons; autore e licenza di ciascuna sono indicati nel corso, sotto l'immagine.
